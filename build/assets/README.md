# Optional assets

Put optional files here before running `04-configure.sh`:

* `wallpaper-hawk-data-recovery.png` — a desktop wallpaper. It is installed as the system default
  (`/usr/share/backgrounds/hddlive/`, zoom style). Tip: use a 4:3 canvas (e.g. 1672x1254) with the artwork centered or
  right-aligned on a dark background, so zoom never crops it on 4:3 / 16:10 screens. If the file is missing the stock
  Xubuntu wallpaper is kept.

No other file in this folder is required.
